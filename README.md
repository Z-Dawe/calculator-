# Calculator

A python 3 calcuylator used from the terminal, built step by step in SCCM4910

## What it will do

Add, Subtract, Multiply and divide two numbers; the results will display inside of the terminal


## How will it run

From week 3: python3 calculator.py
Enter first number, operator ( + - * /) then a second number
The program will then print the result followed by the answer.

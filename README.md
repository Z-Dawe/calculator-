# Calculator

A python 3 calcuylator used from the terminal, built step by step in SCCM4910

## What it will do

Add, Subtract, Multiply and divide two numbers; the results will display inside of the terminal


## How will it run

From week 3: python3 calculator.py
Enter first number, operator ( + - * /) then a second number
The program will then print the result followed by the answer.

# Run: python3 calculator.py

To run the program first open the software and press the play icon.
Once the program has started input the first number and press enter.
One you have entered the first number add what symbol you would like to use to add, divide, minus or multiply
Then add your final number and click enter.
The result should be the answer to the question you have asked with decimals at the end.
